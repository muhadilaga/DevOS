# Project Standard

## Struktur default
- `src/` source code
- `tests/` test
- `docs/` dokumentasi
- `scripts/` utility dan automation
- `assets/` resource statis
- `config/` konfigurasi
- `build/` artifact build sementara
- `dist/` artifact distribusi
- `release/` paket rilis

## Prinsip
- Source code tetap kecil dan terpisah jelas
- Artifact build regenerable
- README menjelaskan tujuan project
- File konfigurasi tidak memakai path absolut bila bisa dihindari
