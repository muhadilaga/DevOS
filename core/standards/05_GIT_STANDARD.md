# Git Standard

## Branch
- `main` untuk baseline stabil
- Branch kerja memakai nama pendek dan jelas

## Commit
- Satu commit satu tujuan
- Pesan commit ringkas dan deskriptif
- Jangan commit file secret atau artifact besar

## Tag
- Tag hanya untuk milestone penting
- Gunakan format konsisten

## Release
- Release harus reproducible
- Sertakan changelog bila relevan
- Artifact release harus terpisah dari source code
