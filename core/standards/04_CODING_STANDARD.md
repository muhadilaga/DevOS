# Coding Standard

## Python
- Ikuti PEP 8
- Gunakan virtual environment per project bila perlu
- Hindari path absolut di source
- Pisahkan entrypoint, logic, dan config

## JavaScript
- Gunakan struktur modul yang jelas
- Hindari side effect global
- Simpan config di file terpisah

## PowerShell
- Gunakan cmdlet penuh
- Hindari alias singkat
- Buat script idempotent bila mungkin

## Markdown
- Judul jelas
- Daftar ringkas
- Contoh singkat dan langsung
- Hindari redudansi
