# DevOS

An AI-Native Developer Workspace Framework

## Vision

DevOS adalah framework untuk membangun workspace developer yang konsisten, terdokumentasi, dan siap bekerja dengan berbagai AI coding agent melalui standar engineering yang dapat diaudit, dipelihara, dan direproduksi.

## Mission

- Standardize developer workspaces
- Unify AI coding agents
- Reduce repetitive setup
- Improve documentation
- Improve maintainability
- Improve reproducibility

## Core Principles

- Safety First
- Documentation First
- Consistency Over Convenience
- Automation When Safe
- Human Approval
- Small Reversible Changes
- AI Assists, Humans Decide

## Architecture Overview

DevOS is organized as a documentation-led framework. `core/` holds policies, standards, and manifesto. `profiles/` defines workstation profiles. `prompts/` contains agent-specific prompt layers. `templates/` provides reusable scaffolds. `scripts/` and `tests/` stay separate so automation and validation remain clear.

## Project Structure

- `core/` policy, standards, manifesto
- `profiles/` workstation profiles
- `prompts/` universal and agent-specific prompts
- `templates/` reusable blueprints
- `scripts/` utility scripts
- `tests/` validation
- `examples/` reference material
- `assets/` supporting files
- `.github/` repository metadata
