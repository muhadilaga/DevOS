# Getting Started

## What this repository is

DevOS is a framework for developer workspaces.

## How to read it

1. Read `README.md`
2. Read `docs/vision.md`
3. Read `docs/manifesto.md`
4. Read `docs/architecture.md`
5. Read `core/policies/`
6. Read `core/standards/`
