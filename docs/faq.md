# FAQ

## Is DevOS a prompt collection?

No. DevOS is a framework.

## Is DevOS a script pack?

No. Scripts are only one part of the system.

## Why so much documentation?

Because the framework must be auditable and reproducible.

## Where are the rules?

In `core/policies/` and `core/standards/`.

## Where do projects go?

In `D:\Dev\Projects`.
