# Contributing

## Purpose
Contributions must improve DevOS as a framework for developer workspaces.

## Workflow
1. Read policy and standards in `core/`
2. Keep changes small and reversible
3. Update documentation when behavior changes
4. Prefer auditability over convenience

## Rules
- Do not add secrets
- Do not break reproducibility
- Do not mix unrelated changes
- Do not introduce undocumented behavior
